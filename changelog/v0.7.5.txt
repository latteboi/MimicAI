v0.7.5 Beta — 2026-10-27 (UTC)
Short-Term Memory moves to the Memory tab, and reaches further.
## **Added**
- **`/thanks`**: ways to support MimicAI, with a Ko-fi tip or a vote or review on Top.gg. It unlocks nothing: every feature stays free for everyone.
- **Always Read Synopsis**, in `/profile manage` → Memory → Set STM Parameters. On by default, as before: the character reads a session's synopsis however long ago it was written. Off, it reads it only while it is still inside its Short-Term Memory, like any other turn.
- **Characters see custom emojis.** A server emoji someone posts reaches the cast as its `:name:` and as a picture, each one once however often it is used, up to 4 a round on top of the usual attachments. Shown while the session's Server Context is on; off, an emoji is its name alone. Before, characters read it as raw `<:name:id>` markup.
- **Branch from Here** (right-click a message → Apps): a public thread that carries the session up to that message, with its cast and settings, and goes on from there while the channel carries on unchanged. Anyone who may create threads in the channel can branch, and Discord's own Create Thread on a session's message does the same. The characters are the same characters, so their memories, mood and bonds carry between a branch and the channel. The invite now asks for Create Public Threads, which a server that added MimicAI before can give its role; `/start` shows if it is missing.
- **Token Advice**, in `/profile manage` under the tabs and in `/session config` beside Start / Update Session: what each setting that is on costs per reply, 🔴 large to 🟡 small, with a dropdown to each. A profile's also shows the text it sends every reply; a session's, how many replies each message gets and what each character's replies cost.
- **Fixed Examples**, in `/profile manage` → Training: up to 20 examples of how the character speaks, sent with every reply, where a training example is sent only when a message resembles it. The line before the reply is optional. They go with the profile into an export or a copy, and the content rating reads them as it reads the lorebook.

## **Changed**
- **A character card's example dialogue is imported as fixed examples**, sent with every reply as SillyTavern sends it, instead of training examples. Save spends no embedding calls on them, and a character's line with nothing before it is kept, not skipped.
- **Short-Term Memory is on the Memory tab**, as Set STM Parameters, instead of in Set Generation Parameters, and goes up to 200 turns instead of 50. New profiles start at 50 instead of 20, the point at which a session folds its oldest turns into the synopsis; existing profiles keep what they have.
- **Session Config → Compaction**: the switch is now called Toggle Compaction.
- **New profiles read images at Medium** (Set Media Input Resolution), about 560 tokens an image instead of the 1,120 Gemini 3 spends at Model default. Existing profiles keep what they have.
- **The AI Director, the Rolling Synopsis and Training Analysis think at Medium**, with a dynamic budget, instead of Low capped at 512 tokens -- each where you have not set its effort yourself.

## **Fixed**
- **Proactivity waits for a quiet channel.** It fired even mid-conversation, and once the cooldown passed it rolled every minute, so "10% every 300s" ran at about four rounds an hour. Now the chance is rolled once each time the channel has been quiet for the cooldown, and any message starts the wait over.
- **Discord's own notices read as what they are.** A member joining or boosting, a pin, or a thread started in a session's channel reached the cast as an empty message from that person, and a sticker as nothing at all. The characters now read Discord's line for it, as `[Discord: Ana joined the party.]`, and see a sticker as well as its name (Discord's own animated default stickers by name alone), and answer either as they would any message.
