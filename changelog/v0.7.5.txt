v0.7.5 Beta — 2026-10-27 (UTC)
Short-Term Memory moves to the Memory tab, and reaches further.
## **Added**
- **`/thanks`**: ways to support MimicAI, with a Ko-fi tip or a vote or review on Top.gg. It unlocks nothing: every feature stays free for everyone.
- **Always Read Synopsis**, in `/profile manage` → Memory → Set STM Parameters. On by default, as before: the character reads a session's synopsis however old. Off, only while it is inside its Short-Term Memory.
- **Characters see custom emojis.** A server emoji someone posts reaches the cast as its `:name:` and as a picture, once each, up to 4 a round, while Server Context is on; off, by name alone. Before, characters read raw `<:name:id>` markup.
- **Branch from Here** (right-click a message → Apps): a public thread carrying the session up to that message, with its cast and settings, while the channel carries on. Anyone who may create threads can branch, and Discord's Create Thread on a session's message does the same. Memories, mood and bonds carry between a branch and the channel. The invite now asks for Create Public Threads; `/start` shows if it is missing.
- **Token Advice**, in `/profile manage` and `/session config`: what each setting that is on costs per reply, 🔴 large to 🟡 small. A profile's also shows the text it sends every reply; a session's, how many replies each message gets and what each costs.
- **Fixed Examples**, in `/profile manage` → Training: up to 20 examples of how the character speaks, sent with every reply, where a training example is sent only when a message resembles it. They go with the profile into an export or copy, and the content rating reads them.
- **`/import` adds examples to a profile you own**: set `profile_name`, and `add` to fixed_examples or training_examples. A .txt of `SAID:`/`REPLY:` blocks split by `---`, SillyTavern dialogue, a JSON list of said/reply, or a card's example dialogue. Duplicates are skipped; a training example needs a SAID and costs one embedding call.

## **Changed**
- **A character card's example dialogue is imported as fixed examples**, as SillyTavern sends it, instead of training examples: no embedding calls, and a line with nothing before it is kept.
- **Short-Term Memory is on the Memory tab**, as Set STM Parameters, and goes up to 200 turns instead of 50. New profiles start at 50 instead of 20; existing profiles keep theirs.
- **Session Config → Compaction**: the switch is now called Toggle Compaction.
- **New profiles read images at Medium**, about 560 tokens an image instead of 1,120. Existing profiles keep theirs.
- **The AI Director, the Rolling Synopsis and Training Analysis think at Medium**, dynamic budget, instead of Low capped at 512 tokens, where you have not set it.

## **Fixed**
- **Proactivity waits for a quiet channel.** It fired mid-conversation, and past the cooldown rolled every minute, so "10% every 300s" ran about four rounds an hour. Now the chance is rolled once each time the channel has been quiet for the cooldown.
- **Discord's own notices read as what they are.** A join, boost, pin or new thread reached the cast as an empty message, and a sticker as nothing. Characters now read Discord's line, as `[Discord: Ana joined the party.]`, and see a sticker and its name.
